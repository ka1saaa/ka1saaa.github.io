# 论文助手 PaperAssistant

最近读英文论文读到麻木：找论文要去 arXiv 搜，下载下来丢进各种翻译工具，翻出来要么排版全乱、公式变成乱码，要么 PDF 一页 HTML 三页；想精读还得开着翻译软件、词典、PDF 阅读器三个窗口来回切。

于是自己写了一个本地工具 **论文助手（PaperAssistant）**，把这些步骤揉成了一个网页：**搜论文 → 一键翻译（保留原版排版）→ 内置阅读器里划词批注、划词 AI 解释 → AI 帮你概括全文画思维导图**。

项目地址：**[https://github.com/ka1saaa/PaperAssistant](https://github.com/ka1saaa/PaperAssistant)**

最近又给它做了一轮大更新：**独立桌面窗口版**（双击 exe 直接用，不用开浏览器）、**批注导出笔记**、**术语表**、**深色模式**。下文全部覆盖。

## 它能干什么

### 1. 三种方式进论文

- **联网搜索**：输入标题或关键词，同时搜 arXiv 和 Semantic Scholar，结果合并去重；**直接输中文也行**（自动把关键词译成英文再搜）
- **本地上传**：拖拽 PDF 进网页，出版社付费墙里下载的论文也能翻
- **粘贴 arXiv 编号或链接**：`1706.03762`、`https://arxiv.org/abs/...`、任意 PDF 直链都认

### 2. 保留原版排版的翻译

这是和其他"论文翻译"工具最大的差别。它基于开源的 pdf2zh / BabelDOC 引擎，在**原 PDF 的文字层上做替换**，翻译完：

- 公式还是原来的公式，位置分毫不差
- 图表、表格、双栏排版、超链接全部保留
- 还能顺手生成一份「左页英文 / 右页中文」的**双语对照版**，精读核对特别舒服

### 3. 内置阅读器：批注 + 划词解释 + 笔记导出

翻译完不用再开别的软件，任务卡片上点「阅读」直接进入内置阅读器：

- **连续滚动阅读**：三份文档（原文/译文/双语对照）随时切换，像刷网页一样往下滚
- **划词批注**：选中一段文字写笔记，自动记录在哪个文档哪一页，点批注卡片的徽章直接跳回去
- **划词解释**：选中看不懂的术语或句子（英文中文都行），AI 结合这篇论文的上下文给你解释，解释里的相关术语还能继续点开
- **导出学习笔记**：批注一键导出成结构化 Markdown（引用原文 + 笔记 + 页码），直接进 Obsidian/Typora
- **目录导航**：论文书签章节树，点击跳页

### 4. AI 帮你"预读"论文

点「AI 概括」，几十秒后得到：

- **中文摘要**：按"研究问题 / 方法 / 实验结果 / 结论与贡献"四节分好
- **思维导图**：论文结构的可视化导图，组会前救急神器
- **关键词卡片**：8-10 个核心术语，点开就是 AI 解释

概括结果会缓存，重复打开不重复花钱。

### 4. 术语表（专业翻译必备）

点「术语表」按钮，每行一条 `英文,中文`（如 `LLM,大语言模型`），保存后翻译全文译法一致——模型名可以固定不译，领域缩写不再每次翻得不一样。实测带术语表翻译后 "Transformer" 全文保持原样。

### 5. 深色模式 + 访问密码

夜间读论文不刺眼的深色模式（一键切换，记住偏好）；如果想在平板/手机上用，把服务开到局域网后还能设置**访问密码**，不怕被邻居蹭。

## 双击就是桌面应用

不想开浏览器？现在它有**桌面窗口版**：

- 双击 `论文助手.exe`（或开发态的 `论文助手.bat`）→ 直接弹出独立窗口，关窗即退出
- 打包版整个文件夹拷给同学朋友就能用，**对方不需要装 Python**
- 数据（论文、批注、笔记、历史）全部存在本地

![内置阅读器](/img/paper-assistant-reader.png)

## 怎么用

前提：装好 Python 3.10+（Windows）。

1. 下载项目后**双击 `论文助手.bat`**——首次运行自动建环境、装依赖、生成配置，然后弹出独立桌面窗口
2. 配置一个大模型 API Key（智谱 GLM / DeepSeek / OpenAI / Kimi 都行）：点窗口左下角的模型状态栏 → 选服务商 → 贴 Key → 测试连接 → 保存，**即时生效**
3. 开始搜论文、传 PDF、翻译、批注

（喜欢浏览器的话，双击 `start.bat` 也行；想打包成免安装 exe 分享给别人，仓库 README 里有一条命令的打包方法。）

没有 Key 也可以先在模型设置里切「免费试用服务」零成本体验。

**费用参考**（用便宜档模型）：翻译一篇 10 页论文约 0.03-0.1 元，AI 概括一次几分钱。所有数据（论文、批注、任务历史）都只存在本地，不上传任何第三方。

详细的十三节教程（含故障排查、FAQ）在仓库的 [使用教程.md](https://github.com/ka1saaa/PaperAssistant/blob/main/使用教程.md)。

## 技术上的一些点

给感兴趣的朋友：

- **Python 3.10+ / FastAPI** 单服务，无 Node 构建链，前端是原生 JS 单页
- 翻译引擎封装 **pdf2zh-next (BabelDOC)**，子进程运行 + 实时解析 rich 进度条换算成网页进度
- 论文搜索并发聚合 **arXiv API + Semantic Scholar API**，标题归一化去重，处理了 S2 匿名限流
- **PDF 阅读**用的是「服务端 PyMuPDF 渲染页面 PNG + pdf.js 文字层叠加」的方案——文字选中、批注定位都靠文字层，显示走服务端渲染，兼容性最好
- 任务系统：asyncio 队列（并发 2）、SQLite 历史、重启恢复、产物文件生命周期管理（删任务连批注概括一起清）
- 统一的 OpenAI 兼容 LLM 客户端，翻译/概括/解释/搜索词翻译共用，还处理了推理模型 `max_tokens` 被思考耗尽返回空内容的问题
