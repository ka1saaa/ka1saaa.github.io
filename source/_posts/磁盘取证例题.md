# 磁盘取证
磁盘取证是取证的一类常见题型，有不少比赛也曾出过这类题目，但是学起来并不轻松，最关键的是磁盘取证或者说取证这类题目的工具，基本都是收费的，并且价格不菲，就比如接下来的例题，官方wp都是付费工具，但对于我这种区来说，兜比脸干净，只能用一下其他法子了

## 1\.DASCTF最后一战

首先下载附件是1z\.vmdk，我们需要先打开磁盘文件，修复里面的内容

先用FTK imager挂载，然后再用DiskGenius修复

得到秘籍\.docx和$R46979F\.txt，就想到了vc挂载解密txt文件，但是没有密钥，所以我们要去找，

由于docx其实和zip是差不多的，所以我们可以把\.docx改为\.zip，方便我们去查看里面的隐藏内容，在秘籍\\word\\theme目录下我们看到一个bat文件，打开发现一串类似base64的编码



得到密钥`th1s_14_y0ur_key!!!!2333`

然后去解密txt，这个时候要用到VeraCrypt，输入密钥解密后得到了txt文件


点开里面发现没有flag，只有一篇三体的文章，这个时候需要脑洞一下，用dead\_end\.txt再去解密$R46979F\.txt，

先卸当前挂载的，再使用密钥文件去解密，就能发现隐藏的文件和  
`flag1:DASCTF{N0w_u_knOw_H1dden_v0lum3`



告诉了我们第一段flag，然后后面提示是用`U????Klsq`掩码生成字典，然后去解密图片，

```Python
from string import digits, ascii_lowercase

mask = "U?u?d?d?dKlsq"

with open("output.txt", "w", encoding="utf-8") as f:
    for a in ascii_lowercase:
        for b in digits:
            for c in digits:
                for d in digits:
                    passwd = f"U{a}{b}{c}{d}Klsq"
                    f.write(passwd + "\n")

```

得到output\.txt后，对图片密码进行爆破，要用到stegseek



得到密码后使用steghide图片解密，



得到`flag2:Of_v3r@cr1pt&90_0nnnnnnnnnnn!!!a>?#P2}`

DASCTF\{N0w\_u\_knOw\_H1dden\_v0lum3\_Of\_v3r@cr1pt\&90\_0nnnnnnnnnnn\!\!\!a\>?\#P2\}

## 2\.2022蓝帽杯计算机取证\_3

打开附件是一个1\.dmp和G\.E01文件，题目要求是找出bitlocker分区某office文件中存在的flag值，

首先我们可以先挂载一下G\.E01，发现是加密的，所以很明显这道题就是要找密码解密磁盘，一般都是内存里藏 BitLocker 密钥，所以我们要通过对1\.dmp分析，

提取密钥我们有很多种办法

1\>使用Elcomsoft工具，把内存镜像中的密钥导出成evk格式的，然后再去解密，得到bitlocker密钥，解密bitlocker分区



可以得到恢复密钥`368346-029557-428142-651420-492261-552431-515438-338239`



2\>直接用dmp进行爆破解密，要用到`Passware Kit Forensic-Decrypt `工具

在`Full Disk Encryption`分区，选择`Bitlocker`，分别导入G\.E01和1\.dmp


得到恢复密钥

接下来挂载G\.E01输入恢复密钥，就可以得到里面的文件，题目说的是某office文件，而磁盘里面只有pptx和docx两个office文件，所以flag肯定在这两个里面，但是发现两个都加密了，注意到有一个pass\.txt，打开是很多类似密码的字符，所以想到了字典爆破密码，

对于office文件的密码爆破，我们用到`office2john.py`工具

```Plain Text
python office2john.py 从渗透看取证.pptx
```

将得到的哈希值从`$office$2007`* *到末尾保存到hash\.txt

```Plain Text
hashcat -m 9400 -a 0 hash.txt pass.txt 

hashcat -m 9400 -a 0 hash.txt pass.txt --show
```


得到密码打开pptx就得到flag


## 3\.2022蓝帽杯计算机取证\_4

解密后的磁盘中还有一个新建文本文档\.txt没有用到，所以猜测flag和它有关，这个txt也是加密的，根据题目描述的TrueCrypt加密，这里我们对它进行解密，使用`passware kit forensic`，





虽然没有得到密码但是文件成功解密了，我们对解密后的新建文本文档\-unprptected\.txt分析，binwalk分析后发现有隐藏文件



得到一个zip，里面有一个加密的txt文件，尝试爆破，爆破成功得到密码，



输入后得到flag
